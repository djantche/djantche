## `~/projects`

**[Duelborne](https://github.com/djantche/duelborne)** — a multiplayer card-duel game that runs in the browser. I wanted to play with my little brother without buying every card, so I built my own game. A Node server runs a real rules engine (ocgcore compiled to WebAssembly); any phone, tablet or PC on the network just opens a web page.
